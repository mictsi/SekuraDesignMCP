Component gallery

Every component below is rendered from the same stylesheet the MCP server serves. Switch the theme in the header and watch what changes — and, more instructively, what does not.

Nothing on this page sets a colour, a font size or a spacing value. Every one comes from a semantic token, which is why one theme switch re-renders all of it correctly.
